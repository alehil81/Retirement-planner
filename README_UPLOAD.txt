Retirement Planner v2

Upload ALL files in this folder to the ROOT of the GitHub repository:
- index.html
- styles.css
- retirement_app.js
- manifest.json
- sw.js
- icon.svg
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Important:
The public source uses generic demo defaults. Existing locally saved inputs from v1 are migrated automatically on the same browser/device.

New features:
- Separate annual contribution increases for VOO and 401(k)
- Year-by-year retirement decumulation through age 95
- Approximate after-tax retirement income
- Need-based 401(k) withdrawal based on after-tax spending gap
- Retirement balance milestones at 70/80/90/95
- Post-edit validation without fighting the user while typing
- Save current values as personal local defaults
- Export/import JSON backup
- PWA/Home Screen support and offline cache
